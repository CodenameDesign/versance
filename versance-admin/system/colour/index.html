Rules
  • Always use the token (var(--color-primary)), never the hex
  • Indigo (--color-primary) is the only accent for actions, links and focus; the web app's green is for success and toggles
  • Severity colours (--color-danger, --color-warning) mean risk, not decoration
  • Body text is black on white (contrast 21.0:1). Muted and faint text are for labels and placeholders only
