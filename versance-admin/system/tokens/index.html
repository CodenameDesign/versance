Section 06 — Design tokens

Design tokens

The system's values as named custom properties and as JSON, ready to use in code or a design tool.

Naming
  • Colours are --color-<name>
  • Type is --font-size-<name>, --line-height-<name>, --font-weight-<name>
  • Space, radius and shadow are --space-<n>, --radius-<name>, --shadow-<n>
  • Use the token, never the raw value
