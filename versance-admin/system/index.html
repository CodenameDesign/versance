Developer system

How the Versance interface is built: type, colour, foundations and components, in a form a developer or an AI assistant can use.

What this is
  • One reference for building Versance admin tools and prototypes in the Versance look
  • The tokens are based on two sources: the web app (versance.html) and the browser-extension design browser-extension/style-v1/. Every token says which one it comes from; values neither defines are tagged Ours
  • Use the tokens, not hard-coded values. The same data produces these pages, the CSS and JSON tokens, and the AI files
The two sourcesWhere the tokens come from
SourceWhat it supplies
Web appversance.html (Talk to Edgar): white sidebar 230px, green accent #5AC47E, light-blue active nav #C7E2F0, Figtree and Roboto Mono, a dark theme
Extension style-v1browser-extension/style-v1/: one indigo accent #324EFE with tints, 14px body, 8px buttons, 10px inputs, 12px cards, severity colours
This adminIndigo accent and style-v1 type and shapes; the web app's sidebar width, shadows and green for success; a near-black #0A1922 sidebar
Principles
  • One accent. Indigo #324EFE for links, actions, focus and selected states; pale tints for hover and disabled
  • Light surfaces, hairlines. White cards, #F9F9F9 panes, #D9DDE5 borders
  • Figtree everywhere, Roboto Mono only for code and the web app composer
  • Pills and soft corners. 8px buttons, 10px inputs, 12px cards, fully rounded pills and tabs
