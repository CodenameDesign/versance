Developer system

How the Versance interface is built: type, colour, foundations and components, in a form a developer or an AI assistant can use.

What this is
  • One reference for building Versance admin tools and prototypes in the Versance look
  • One set of tokens, based on the web app (versance.html) and the browser-extension baseline browser-extension/style-v1/. Every token says which one it comes from; values neither defines are tagged Ours
  • Use the tokens, not hard-coded values. The same data produces these pages, the CSS and JSON tokens, and the AI files

Principles
  • One accent. Indigo #324EFE for links, actions, focus and selected states; pale tints for hover and disabled
  • Light surfaces, hairlines. White cards, #F9F9F9 panes, #D9DDE5 borders
  • Figtree everywhere, Roboto Mono only for code and the web app composer
  • Pills and soft corners. 8px buttons, 10px inputs, 12px cards, fully rounded pills and tabs
