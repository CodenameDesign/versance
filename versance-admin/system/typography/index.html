Section 02 — Typography

Type

One typeface, a short scale, and a hard rule: sizes come from the tokens.

TypefaceFigtree

Figtree is the typeface of the web app and the extension (weights 400 to 800). Roboto Mono is used for code and the web app composer. Letter spacing is normal; the web app hero title uses -0.5px.

Weights. 400 body, 600 pane titles, selected pills and table heads, 700 buttons, tags and titles. Set -webkit-font-smoothing: antialiased on body.
